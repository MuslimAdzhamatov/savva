# Проект: Сайт-меню для кофейни Savva

Это проект сайта-меню для кофейни Savva. В папке лежит QR-код (изображение) — при сканировании он ведёт на Google Drive с фактическим меню кофейни (фото/документ с позициями и ценами). Меню нужно использовать как основу для контента сайта — с описанием и ценами.

## Меню

- Ссылка на меню (Google Drive): https://drive.google.com/file/d/1hsfYMPRwrbNqr2L-KM_wjPJQp0wbSzGy/view?usp=drivesdk
- QR-код в папке проекта ведёт на эту же ссылку.
- При наполнении сайта бери названия позиций, описания и цены именно из этого меню.

## Цветовая палитра

Использовать цвета из фирменного меню кофейни:
- `#747a61` — основной цвет
- `#dac6ab` — вторичный/акцентный цвет
- `#70808C` — дополнительный цвет, использовать аккуратно (пробовать в деталях/акцентах, смотреть по месту, сочетается ли с основной палитрой)

## Правила работы

- После каждого завершённого и рабочего изменения делай `git commit` с понятным сообщением на русском языке, кратко описывающим суть изменения.
- Коммить только рабочий, проверенный код — не коммить сломанные промежуточные состояния.
- Не переписывай и не удаляй исходные файлы (например, QR-код) без явного запроса.
- Если правишь несколько независимых вещей за раз — делай отдельные коммиты на каждую, а не один большой.
